# Executable test case (`.test/`)

A complete, self-contained run of the workflow on synthetic miniature
sections — one Xenium-like, two Visium-like. It executes every stage for real
(loading, QC, normalization, clustering, markers, spatial graph, neighborhood
enrichment, Moran's I, the report) and then **asserts the numbers that come
out**, not merely that files appeared.

Runs in about a minute on two cores once the conda env exists. Nothing is
downloaded.

## Running it

```bash
python .test/make_testdata.py       # regenerate inputs (optional; they are committed)
snakemake -s workflow/Snakefile -d .test --sdm conda --cores 2 all impute_all
python .test/assert_outputs.py      # the actual test
```

`impute_all` runs the opt-in imputation with all three methods (scVI trained
for 30 epochs on CPU); `assert_outputs.py` checks those outputs when they
exist and says so when they do not.

`assert_outputs.py` exits non-zero if any assertion fails. That is what CI gates on.

## Why it asserts values

The expected outputs are known **by construction** — `make_testdata.py` plants
them with a fixed seed (`SEED = 20260908`) — rather than being recorded from a
previous run and frozen. A recorded baseline only tells you the output changed;
a constructed one tells you it is *wrong*.

| Planted | Asserted |
|---|---|
| `n_low` low-quality cells/spots per section (all rates × 0.05) | exactly that many rows dropped as `low_counts`; every normal cell kept; `n_cells_kept` matches to the cell |
| `n_mito` high-mito spots per Visium section (mito λ = 40) | exactly that many dropped as `high_mito`, each > 40 % mito |
| 7 Xenium control features (negative-control probes/codewords, unassigned) | counted into `control_frac`, removed from the gene matrix: 60 genes after loading |
| 4 Visium barcodes in the matrix flagged `in_tissue = 0`, plus a ring of out-of-tissue positions absent from the matrix | dropped at load time; `n_cells_raw` equals the in-tissue count |
| two spatial domains with disjoint 20-gene marker programs | ≥ 2 Leiden clusters, ≥ 90 % of cells in a cluster dominated by their own domain, both domains recovered; a domain cluster's top-5 markers hold ≥ 3 of its domain's genes |
| domain markers vary in space, housekeeping genes do not | the top-10 Moran's I genes are all domain markers, no housekeeping gene among them, best I > 0.5, housekeeping I < 0.3 |
| spatially coherent domains | every cluster is self-enriched (positive diagonal) in the neighborhood-enrichment z-scores |
| three sections | exactly three summary rows; the report has one section per sample with embedded images; the final `.h5ad` carries `obs/leiden`, `obsm/spatial` and the spatial graph |
| dropouts in the domain markers (Poisson counts) | for each of MAGIC, ALRA and scVI: the domain markers' zero fraction drops, their median observed-vs-imputed correlation is > 0.3, imputed values stay finite and non-negative and still separate the two domains; the imputation summary has one row per section × method |

## The synthetic dataset

Generated by `make_testdata.py` — deterministic, needs only numpy + h5py:

- **Genes** 60: 20 domain-A markers, 20 domain-B markers, 15 housekeeping,
  5 mitochondrial. Poisson counts: markers λ = 6 in their domain / 0.2
  outside, housekeeping λ = 3.
- **xenium_1** 900 cells on a jittered 30 × 30 grid in a 1000 × 1000 µm
  field, domain A left / B right; `cell_feature_matrix.h5` (with the control
  features) + `cells.csv.gz` (centroids, areas).
- **visium_1 / visium_2** 24 × 24 and 20 × 24 hexagonal spot grids
  (~100 px spacing), domain A top / B bottom; `filtered_feature_bc_matrix.h5`
  + `spatial/tissue_positions.csv` + `scalefactors_json.json` (no images —
  the loader tolerates their absence).
- **Truth** per cell in `truth/<sample>_truth.tsv` (domain, quality).
